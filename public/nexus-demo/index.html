📖 Guía de Uso Paso a Paso

Sigue estos pasos para explorar todas las funcionalidades de Nexus Empresarial.

1

Selecciona un usuario y entra a la demo

Haz clic en "Abrir Demo Interactiva" en la pestaña Inicio. Verás la pantalla de login con 4 opciones de rol.

Selecciona el rol que quieras (ej: Administrador) y entra con las credenciales de la pestaña "Usuarios Prueba".

2

Explora el Dashboard

Una vez dentro, verás el panel principal con el selector de empresa en la esquina superior izquierda.

Cambia entre empresas (CODESIN, TECFOR, SERMAT) para ver datos específicos de cada una.

3

Navega por los módulos

En la barra lateral izquierda encontrarás accesos a:

📋 Recursos & OT → Gestiona órdenes de trabajo
✅ Aprobaciones → Flujo de validación
🔐 Accesos → Habilitaciones y cursos
📅 Vigencias → Alertas de vencimiento
💬 Comunicaciones → OS/PE y bajas
🎯 Control → Semáforo de cumplimiento
📊 Auditoría → Reportes semanales
4

Prueba interacciones clave

Intenta estas acciones:

✓ Marca documentos como completados (checkboxes)
✓ Cambia estado de aprobación (Nuevo → Avalado)
✓ Desafecta o vuelve a activar recursos
✓ Genera un reporte semanal y descárgalo en Excel
5

Inicia sesión con otro rol

Vuelve a la página de login (botón logout o actualiza la página) e inicia sesión con otro rol.

Observa cómo cambian los permisos y los datos visibles según el rol (ej: Auditor ve todo, Empresa solo sus recursos).

6

Consulta el reporte ejecutivo

Vuelve a la pestaña Inicio y abre "Reporte Ejecutivo". Este es un documento profesional con KPIs, gráficos y análisis de cumplimiento.

Puedes imprimirlo a PDF usando Ctrl+P o Cmd+P.

🔒 Seguridad y Privacidad

Información sobre cómo se protegen tus datos en Nexus Empresarial.

✓ Privacidad de Datos

  • Sin servidores remotos: Nexus no se conecta a ningún servidor. Todo ocurre en tu navegador.
  • Datos locales: Los datos se guardan solo en localStorage de tu navegador, nunca se envían a internet.
  • Sin rastreo: No hay cookies de rastreo, analíticas externas o envío de información.
  • Puedes verificar: Abre F12 → Network mientras usas la app. Verás que no hay peticiones HTTP a servidores.
  • Fácil de limpiar: Limpia localStorage en cualquier momento desde los ajustes del navegador.

✓ Seguridad de Credenciales

  • Credenciales de prueba: Las credenciales proporcionadas son ficticias y solo para demostración.
  • Sin hash real: Las contraseñas no se hashean (no es necesario en una demo local).
  • No usar para producción: Nexus es una demo interactiva, NO es una plataforma de producción.
  • Control de acceso por rol: Los permisos se validan en el navegador según el rol seleccionado.

✓ Requisitos Técnicos Mínimos

  • Navegador moderno: Chrome 60+, Firefox 55+, Safari 11+, Edge 79+
  • JavaScript habilitado: La app requiere JavaScript. Si lo tienes deshabilitado, no funcionará.
  • localStorage disponible: El navegador debe permitir localStorage (no está deshabilitado).
  • Sin extensiones peligrosas: Algunas extensiones pueden interferir. Si tienes problemas, desactívalas temporalmente.
  • Conexión a internet (solo para descargas): La app funciona offline, pero necesitas internet para descargar Excel.

✓ Instrucciones para Usar Offline

  • Paso 1: Descarga los 3 archivos HTML (index.html, nexus-pitch-demo.html, informe-ejecutivo-nexus.html) en una carpeta.
  • Paso 2: Abre index.html con tu navegador (doble clic).
  • Paso 3: Úsalo sin internet. Los datos se guardan localmente en tu navegador.
  • Paso 4: Para descargar reportes en Excel, necesitarás internet solo para esa función específica.
  • Nota: En algunos navegadores, localStorage puede tener limitaciones si abres archivos locales (usa un servidor local si tienes problemas).

✓ Cómo Compartir Seguramente

  • Comparte los archivos HTML: Puedes enviar por email los 3 archivos. No contienen datos sensibles.
  • Usa un servidor web: Si lo despliegas en un servidor web, asegúrate de usar HTTPS.
  • Sin credenciales reales: Las credenciales en la app son ficticias. Las credenciales reales deben manejarse en producción.
  • Cumplimiento GDPR/CCPA: Como no recopilamos datos, no hay preocupaciones de privacidad.
  • Auditoría de código: Todo el código está en el HTML. Puedes leerlo, modificarlo y verificarlo.

⚠️ Disclaimer

Nexus Empresarial es una demo interactiva, no una plataforma de producción.

Esta herramienta está diseñada para demostración, capacitación y validación de conceptos. No debe usarse para manejar datos reales o sensibles. Si implementas un sistema similar en producción, asegúrate de implementar autenticación real, encriptación, auditoría y todas las medidas de seguridad necesarias.
